1. Apa itu JavaScript dan kegunaannya
JavaScript adalah bahasa pemrograman yang biasanya dijalankan di browser untuk membuat halaman web menjadi lebih interaktif. Kalau HTML untuk struktur dan CSS untuk tampilan, JavaScript dipakai untuk mengatur perilaku halaman, misalnya menampilkan pop-up, mengecek isian form, mengubah isi halaman, atau merespons saat user mengklik tombol.
2. Apa itu jQuery dan kegunaannya
jQuery adalah library yang dibuat dari JavaScript untuk mempermudah penulisan kode. Dengan jQuery, hal-hal seperti memilih elemen HTML, menangani event klik, menyembunyikan atau menampilkan elemen, dan membuat efek animasi bisa ditulis dengan kode yang lebih singkat dibanding JavaScript biasa.
3. Perbedaan JavaScript dan jQuery
JavaScript adalah bahasa pemrogramannya, sedangkan jQuery adalah library yang dibangun di atas JavaScript. JavaScript bisa langsung dijalankan di browser, sementara jQuery harus dipanggil dulu lewat file atau CDN sebelum bisa dipakai. Dari segi penulisan, jQuery lebih ringkas, contohnya untuk menyembunyikan elemen cukup menulis $("#kotak").hide();, sedangkan di JavaScript biasa harus menulis document.getElementById("kotak").style.display = "none";. Namun, JavaScript murni sedikit lebih cepat karena tidak memerlukan library tambahan.
